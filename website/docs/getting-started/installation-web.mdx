alphaTab runs in every evergreen browser and in Node.js. Everything needed to render and play a score is bundled — no external runtime dependencies.

npm install @coderline/alphatab

- https://unpkg.com/@coderline/alphatab

Reference the ESM build (`.min.mjs`) for module imports or the UMD build (`.min.js`) for classic script tags.

## Render your first score

The following example loads alphaTab from a CDN and renders a "Hello alphaTab" score written in alphaTex. It runs as-is inside a standalone HTML file — no bundler required:

```html
<div id="alphaTab">
   \title "Hello alphaTab"
   .
   :4 0.6 1.6 3.6 0.5 2.5 3.5 0.4 2.4 |
      3.4 0.3 2.3 0.2 1.2 3.2 0.1 1.1 |
      3.1.1
</div>
<script type="module">
   import * as alphaTab from 'https://cdn.jsdelivr.net/npm/@coderline/alphatab@latest/dist/alphaTab.min.mjs';
   const element = document.getElementById('alphaTab');
   const api = new alphaTab.AlphaTabApi(element, { tex: true });
</script>
```

The output:

<InitDemo />

Once alphaTab is installed via npm, replace the CDN URL with a module import through your bundler:

```js
import * as alphaTab from '@coderline/alphatab';

const element = document.getElementById('alphaTab');
const api = new alphaTab.AlphaTabApi(element, { tex: true });
```

If you are not yet using JavaScript modules, alphaTab also ships a UMD build that exposes a global `alphaTab` variable — reference `dist/alphaTab.min.js` from a classic `<script>` tag and initialize the API the same way.

## Bundler integration

alphaTab spawns Web Workers and Audio Worklets internally. Bundlers may split and rename files, which prevents alphaTab from locating the right worker entry points at runtime. To handle this cleanly, alphaTab ships bundler plugins:

- [Installation (WebPack)](installation-webpack) for WebPack 5 projects, including most Angular setups
- [Installation (Vite)](installation-vite) for Vite-based projects

## Framework integration

alphaTab does not yet ship official wrappers for Angular, React, or Vue. To integrate it in these frameworks:

1. Create a DOM element through the framework's usual mechanism (`ElementRef` in Angular, `useRef` in React, `template ref` in Vue).
2. Instantiate `AlphaTabApi` against that element inside the framework's mount lifecycle.
3. Use the framework's update and unmount hooks to push settings changes and to destroy the API instance when the component unmounts.

The bundler plugins above cover the WebPack and Vite configuration most frameworks depend on. Sample projects for a range of setups are available at [github.com/CoderLine/alphaTabSamplesWeb](https://github.com/CoderLine/alphaTabSamplesWeb).

## Node.js

alphaTab runs in Node.js through both `require` and `import`:

```js
// CommonJS
const alphaTab = require("@coderline/alphatab");

// ESM
import * as alphaTab from '@coderline/alphatab';
```

Only the low-level APIs are exposed on Node.js today. Headless rendering to images through [alphaSkia](https://github.com/CoderLine/alphaSkia) is on the roadmap. See the [Node.js guide](/docs/guides/nodejs) for the full setup.

## Dependencies {#dependencies}

alphaTab has no runtime dependencies of its own. Two assets ship with the package and must be reachable at runtime:

- [Bravura](https://github.com/steinbergmedia/bravura), a [SMuFL](https://www.smufl.org/) music font, supplies every notation symbol alphaTab draws.
- A SoundFont2 file supplies the instrument samples the audio engine plays. alphaTab bundles a SONiVOX-based SoundFont from the [Android Open Source Project](https://source.android.com/), released under the [Apache License](https://www.apache.org/licenses/LICENSE-2.0).

Both files sit next to the alphaTab scripts by default. The bundler plugins linked above copy them into your build output automatically.
