alphaTab is a music-notation SDK that reads Guitar Pro, MusicXML, CapXML, and alphaTex files and produces engraved sheet music with playback. This section catalogs what alphaTab does, grouped by capability. Each entry links into the [API reference](/docs/reference/api/) or a deeper guide for the exact signatures.

## Portable across Web, .NET, and Android {#portable}

alphaTab compiles a single TypeScript core to JavaScript, C#, and Kotlin. API surface, class names, setting names, and event names are identical on every runtime. Code samples on these pages are written in JavaScript; every property and method has the same name on .NET and Android. Platform-specific setup — loading a file, obtaining a container, downloading a byte array — is shown as a placeholder helper like `getAlphaTabContainer()` or `readScoreFile()` that you replace with the natural equivalent for your platform.

Where a capability genuinely differs across platforms, the card names the affected platforms with a small pill.
