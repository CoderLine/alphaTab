alphaTab is a two-way street. A score that came in as MusicXML can leave as a `.gp` your users open in Guitar Pro. Edits made in your app can go back to a database as JSON. The same synth that drives live playback can bake a study track to WAV. Everything on this page is a stable outbound path — pick the format that fits what you want to hand a user, a DAW, or a server.

Every capability below is available on Web, .NET, and Android unless a card names specific platforms. Follow any card into the [reference](/docs/reference/api/) for the exact signature.
