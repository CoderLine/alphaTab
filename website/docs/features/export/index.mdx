alphaTab is a two-way street. Once a score is loaded, you can write it back out as a Guitar Pro file, round-trip it through alphaTex, render it to MIDI, bake the synth output to WAV, or serialize the whole model to JSON for storage and diffing.

Every capability below is available on Web, .NET, and Android unless a card names specific platforms. Follow any card into the [reference](/docs/reference/api/) for the exact signature.
