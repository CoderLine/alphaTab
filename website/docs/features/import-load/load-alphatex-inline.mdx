Write the score directly in your page or your code with alphaTex — no file, no importer plumbing.

<AlphaTab tex={true}>{`
\\title "A short lick"
\\tempo 120
.
:8 3.3 5.3 7.3 8.3 |
   10.3 8.3 7.3 5.3 |
`}</AlphaTab>

## Two ways to feed alphaTex

Set `core.tex: true` on construction and alphaTab reads the container element's text content as alphaTex source. The score renders on the first tick without any imperative call. Use this when the tex is authored alongside the markup — inside a `<div>` in your HTML, a JSX template, a CMS field.

Call `api.tex(text)` post-construction when the source lives in code, a textarea, or an editor state. The method reparses on every call, so wiring it to an `input` event gives you a live preview. The optional second argument picks which tracks render, matching `api.load()`.

Either path routes through `AlphaTexImporter` and fires the same `scoreLoaded` event as any other load.

## What alphaTex looks like

alphaTex is alphaTab's plain-text notation format. A minimal snippet declares metadata with backslash commands, then lists beats grouped by voices and bars:

```text
\title "Two bars"
\tempo 90
.
:4 3.3 5.3 :8 7.3 8.3 7.3 5.3 |
:4 3.3.4 | 
```

The full grammar is documented under [alphaTex](/docs/alphatex/introduction).

## Show it in code

```js
import * as alphaTab from '@coderline/alphatab';

// Path 1: source lives in the DOM element.
// <div id="alphaTab">\title "In markup" . :4 3.3 5.3 7.3 8.3</div>
const container = getAlphaTabContainer();
const inlineApi = new alphaTab.AlphaTabApi(container, {
  core: { tex: true },
});

// Path 2: source lives in code and can change at runtime.
const editableApi = new alphaTab.AlphaTabApi(container, {});
editableApi.tex(`
  \\title "From code"
  \\tempo 120
  .
  :8 3.3 5.3 7.3 8.3
`);

document.querySelector('#tex-input').addEventListener('input', (e) => {
  editableApi.tex(e.target.value);
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific step of obtaining the render target. `core.tex: true` is Web-only because it reads the DOM element's text; on .NET and Android call `api.tex(text)` with the source string instead.
