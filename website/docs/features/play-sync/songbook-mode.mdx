Traditional songbooks notate bends and whammy dips as instant events at the start or end of a beat, not as gradual gestures spread across the note. Two millisecond-based settings control how snappy those events sound when the score's notation mode is `SongBook`.

## Two durations, always in milliseconds

- `player.songBookBendDuration` — how long a songbook bend takes to reach its target pitch. Default `75` ms.
- `player.songBookDipDuration` — how long a whammy dip takes to descend and rise back. Default `150` ms.

These are milliseconds, not MIDI ticks. Bends and dips in songbook style should feel identical at any tempo, so alphaTab measures them against wall-clock time instead of the score's time base.

Lower values sharpen the attack — the bend snaps almost instantly to its target. Higher values soften it into an audible glissando. Values above ~250 ms start to blur the note the bend is attached to; the songbook idiom breaks down.

## When these settings apply

The two durations only take effect when `notation.notationMode` is set to `SongBook`. In the default `GuitarPro` notation mode, bends and dips render and play as full gestures over the note's duration, and these knobs have no effect. Setting them without switching the notation mode is safe — they wait for the mode to change.

## Show it in code

```js
import * as alphaTab from '@coderline/alphatab';

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, {
  core: { file: '/scores/canon.gp' },
  notation: {
    notationMode: alphaTab.NotationMode.SongBook,
  },
  player: {
    playerMode: alphaTab.PlayerMode.EnabledAutomatic,
    songBookBendDuration: 60,
    songBookDipDuration: 120,
  },
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific step of obtaining the render target — a `<div>` on Web, an `AlphaTab` control on .NET, or an `AlphaTabView` on Android. Every other line runs unchanged on all three runtimes.
