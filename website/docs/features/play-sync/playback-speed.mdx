`playbackSpeed` scales the tempo without repitching the audio. Slow a passage down while a student learns the fingering, then step back up to performance speed.

<AlphaTab file="/files/canon.gp" player={true} />

## The property

`playbackSpeed` is a multiplier applied to the score's tempo. `1.0` plays at the notated tempo. `0.5` runs at half speed, `2.0` at double. The playground exposes the full supported range of `0.1` through `3.0`.

The setter takes effect immediately — even mid-playback — so binding it to a slider produces a smooth speed change without interrupting the audio. The pitch stays fixed; only the timing scales. Both the transport clock and the on-screen cursor follow the modified tempo.

Setting `playbackSpeed` while the player is paused stores the value; it applies as soon as `play()` runs.

## Show it in code

```js
import * as alphaTab from '@coderline/alphatab';

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, {
  core: { file: '/scores/canon.gp' },
  player: { enablePlayer: true },
});

const slider = document.getElementById('speed');
slider.addEventListener('input', () => {
  api.playbackSpeed = Number(slider.value);
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific step of obtaining the render target — a `<div>` on Web, an `AlphaTab` control on .NET, or an `AlphaTabView` on Android. Every other line runs unchanged on all three runtimes.
