Grace notes, tuplets, and ornaments carry the small performance details that give a passage its character. alphaTab renders each with the engraving conventions its readers expect.

## Grace notes {#grace}

Grace notes are the small noteheads that lead into a principal beat — the flick of an appoggiatura or acciaccatura that gives a melody its lift. alphaTab honours the source file's on-beat vs before-beat placement and draws the acciaccatura slash where appropriate.

<AlphaTab file="/files/features/GraceNotes.gp5" />

## Tuplets {#tuplets}

Tuplets — triplets, quintuplets, and other non-standard beat subdivisions — appear whenever a passage subdivides a beat outside the meter, from a shuffle triplet to a Chopin quintuplet run. alphaTab renders each with a bracket and ratio label above the beamed group; beat-connected tuplets share a single bracket span.

<AlphaTab file="/files/features/Tuplets.gp5" />

## Trills {#trills}

Trills — the fast alternation between the written note and the pitch above, common on baroque violin lines and lead-guitar sustains — render with a `tr` glyph, and, when the trill spans multiple beats, a wavy line above the staff indicating the duration.

<AlphaTab file="/files/features/Trill.gp5" />

## Mordents and turns {#ornaments}

Mordents and turns are the traditional ornamental figures that decorate a melodic note — a mordent taps the neighbour note once, a turn wraps around the note with its upper and lower neighbours. alphaTab renders upper mordents, lower mordents, and turns as their standard glyphs above the notehead. The example below uses alphaTex to isolate each ornament type.

<AlphaTab tex={true}>{`
\\track "Guitar"
:4 0.3 { turn } 2.3 { iturn } 4.3 { umordent } 5.3 { lmordent } |
:4 7.3 5.3 :2 4.3
`}</AlphaTab>

## Fingering annotations {#fingering}

Fingering marks tell the player which finger to use — the small digits above classical-guitar and piano parts and the picking-hand letters (`p`, `i`, `m`, `a`) on fingerstyle scores. alphaTab renders left-hand and picking-hand fingering as small digits or letters next to the affected notehead.

## Show it in code

Trills and ornaments share the `EffectNoteOrnament` key; fingering has its own. Toggle any of them off for a cleaner rendering:

```js
import * as alphaTab from '@coderline/alphatab';

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, {
  core: { file: '/scores/song.gp' },
  notation: {
    elements: new Map([
      [alphaTab.NotationElement.EffectTrill, false],
      [alphaTab.NotationElement.EffectNoteOrnament, false],
      [alphaTab.NotationElement.EffectFingering, false],
    ]),
  },
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific render target — a `<div>` on Web, an `AlphaTab` control on .NET, or an `AlphaTabView` on Android.
