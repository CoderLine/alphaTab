alphaTab draws every notation category by default. The [`notation.elements`](/docs/reference/settings/notation/elements) map lets you flip individual categories off — score title, tuning, bar numbers, palm-mute brackets, whammy annotations, lyrics, or any of the other entries in the [`NotationElement`](/docs/reference/types/notationelement) enumeration. Reach for it when a chart needs a compact printout, when your renderer already provides its own title bar, or when an editor UI needs to preview one element at a time.

<ToggleElementsDemo showCode={false} />

Flip a checkbox to remove that category from the score. Each toggle maps to one `NotationElement` key on the `notation.elements` map.

## What you can toggle

Every enum entry maps to one rendered piece of the score. The categories fall into four groups:

- **Score info** — `ScoreTitle`, `ScoreSubTitle`, `ScoreArtist`, `ScoreAlbum`, `ScoreWords`, `ScoreMusic`, `ScoreWordsAndMusic`, `ScoreCopyright`.
- **Track chrome** — `TrackNames`, `GuitarTuning`, `BarNumber`, `ChordDiagrams`, `ChordDiagramFretboardNumbers`, `RepeatCount`.
- **Effect bands** — `EffectAlternateEndings`, `EffectChordNames`, `EffectDynamics`, `EffectFermata`, `EffectFingering`, `EffectHarmonics`, `EffectLetRing`, `EffectLyrics`, `EffectMarker`, `EffectOttavia`, `EffectPalmMute`, `EffectPickSlide`, `EffectPickStroke`, `EffectSlightBeatVibrato`, `EffectSlightNoteVibrato`, `EffectTap`, `EffectTempo`, `EffectText`, `EffectTrill`, `EffectTripletFeel`, `EffectWhammyBar`, `EffectWideBeatVibrato`, `EffectWideNoteVibrato`, `EffectLeftHandTap`, `EffectFreeTime`, `EffectSustainPedal`, `EffectGolpe`, `EffectWahPedal`, `EffectBeatBarre`, `EffectNoteOrnament`, `EffectRasgueado`, `EffectDirections`, `EffectBeatTimer`, `EffectCapo`, `EffectCrescendo`, `EffectFadeIn`.
- **Notation glyphs** — `ScoreBendSlur`, `EffectWhammyBarLine`, `EffectNumberedNotationKeySignature`, `EffectHammerOnPullOffText`, `EffectSlideText`, `ParenthesisOnTiedBends`, `TabNotesOnTiedBends`, `ZerosOnDiveWhammys`.

`ZerosOnDiveWhammys` is off by default; every other entry is on by default.

## Show it in code

Pass a `Map` (JavaScript / TypeScript) or a dictionary (JSON, .NET, Kotlin) keyed by the enum. Values are booleans:

```js
import * as alphaTab from '@coderline/alphatab';

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, {
  core: { file: '/scores/song.gp' },
  notation: {
    elements: new Map([
      [alphaTab.NotationElement.EffectWhammyBar, false],
      [alphaTab.NotationElement.BarNumber, false],
      [alphaTab.NotationElement.TrackNames, false],
    ]),
  },
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific render target — a `<div>` on Web, an `AlphaTab` control on .NET, or an `AlphaTabView` on Android.

For JSON input, use the camelCase enum name as the key:

```js
{
  "notation": {
    "elements": {
      "effectWhammyBar": false,
      "barNumber": false
    }
  }
}
```

To flip an entry at runtime, mutate the map on `api.settings.notation.elements` and call [`api.render()`](/docs/reference/api/render):

```js
api.settings.notation.elements.set(alphaTab.NotationElement.EffectLyrics, false);
api.render();
```
