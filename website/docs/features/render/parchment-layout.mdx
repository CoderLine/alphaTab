Parchment layout lays bars out page-style but honors the systems layout embedded in the source file — the row breaks and relative bar widths the engraver chose in Guitar Pro. Reach for it when publishing method books, songbooks, or educational material where the author's line breaks *are* the story — a phrase intentionally left on its own row, a coda pinned to a fresh system. The alternative — letting alphaTab re-pack the bars — would silently rewrite that engraving choice.

## What Parchment reads from the score model

Parchment consults per-track fields when a single track is rendered, and per-score fields when multiple tracks are:

- **`systemsLayout`** — an array describing how many bars land in each row. Consumed row by row until the values run out.
- **`defaultSystemsLayout`** — the fallback bars-per-row once `systemsLayout` is exhausted.
- **`bar.displayScale`** (single track) / **`masterBar.displayScale`** (multi-track) — a relative weight controlling how the available row width is distributed across the bars in that row. Two bars with `displayScale = 1` share the row evenly; a bar with `displayScale = 2` gets twice the space of a `1`.

Prefix and postfix glyphs — clef, key signature, time signature, barlines — keep their natural width. `displayScale` distributes what's left of the row.

## Overriding the source layout

Mutate the model fields in a `scoreLoaded` handler to override what the file carried — useful when adapting an embedded layout for a smaller viewport or when authoring a layout for a score that ships without one.

## Show it in code

```js
import * as alphaTab from '@coderline/alphatab';

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, {
  core: { file: '/scores/song.gp' },
  display: {
    layoutMode: alphaTab.LayoutMode.Parchment,
  },
});

api.scoreLoaded.on((score) => {
  score.defaultSystemsLayout = 4;
  score.masterBars[0].displayScale = 1.5;
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific step of obtaining the render target — a `<div>` on Web, an `AlphaTab` control on .NET, or an `AlphaTabView` on Android. Every other line runs unchanged on all three runtimes.
