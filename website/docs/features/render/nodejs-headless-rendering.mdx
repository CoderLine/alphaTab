Run alphaTab in Node.js to produce SVG or PNG images from a score — for CI thumbnails, PDF pipelines, print-on-demand, or preview generation. No browser, no DOM, no user interface.

The live preview above renders in your browser. In a Node.js pipeline the same score comes out as an SVG string or, with [alphaSkia](https://github.com/CoderLine/alphaSkia) attached, as a PNG buffer you can write straight to disk.

## The Node.js pipeline

alphaTab's core is platform-independent. In Node.js you skip `AlphaTabApi` (which expects a DOM host) and drive the low-level `ScoreRenderer` directly:

1. Load the score bytes with `fs` and hand them to `ScoreLoader.loadScoreFromBytes`.
2. Set `settings.core.engine` to `'svg'` for text output or `'skia'` for PNG.
3. Instantiate `ScoreRenderer`, subscribe to `partialLayoutFinished` and `partialRenderFinished`, and call `renderScore`.
4. Collect the partial results — SVG strings or Skia image handles — and stitch them into your final artifact.

For PNG output, install `@coderline/alphaskia` plus the platform native package (`@coderline/alphaskia-windows`, `-linux`, or `-macos`), enable it via `alphaTab.Environment.enableAlphaSkia`, then render onto an `AlphaSkiaCanvas` and call `endRender().toPng()`.

## Show it in code

```js
import * as alphaTab from '@coderline/alphatab';
import * as fs from 'fs';

const fileData = await fs.promises.readFile(process.argv[2]);
const settings = new alphaTab.Settings();
settings.core.engine = 'svg';

const score = alphaTab.importer.ScoreLoader.loadScoreFromBytes(
  new Uint8Array(fileData),
  settings,
);

const renderer = new alphaTab.rendering.ScoreRenderer(settings);
renderer.width = 1200;

const svgChunks = [];
renderer.preRender.on(() => { svgChunks.length = 0; });
renderer.partialLayoutFinished.on((r) => renderer.renderResult(r.id));
renderer.partialRenderFinished.on((r) => svgChunks.push(r.renderResult));

renderer.renderScore(score, [0]);
await fs.promises.writeFile('out.svg', svgChunks.join('\n'));
```

Swap `engine` to `'skia'` and wire `Environment.enableAlphaSkia` plus an `AlphaSkiaCanvas` to emit PNG instead. The complete PNG walkthrough — Bravura loading, custom text fonts, and the final `toPng()` — lives in the Node.js guide linked below.
