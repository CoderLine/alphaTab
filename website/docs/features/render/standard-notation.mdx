Standard notation is the default rendering for every staff — five lines, clef, key signature, and pitched noteheads with stems.

<AlphaTab tex={true}>{`
\\track "Guitar"
  \\staff{score}
  :4 (1.6 5.5 8.4 10.4 8.3 5.2) |
  :4 (3.6 7.5 10.4 12.4 10.3 7.2) |
  :4 (5.6 9.5 12.4 14.4 12.3 9.2) |
  :4 (3.5 7.4 10.3 12.3 10.2 7.1)
`}</AlphaTab>

## When to show, when to hide

Every `Staff` starts with `showStandardNotation = true`. For a piano or a vocal line you keep it on and turn `showTablature` off. For a guitar chart aimed at players who read tab, do the opposite — hide the score staff and leave tablature (plus rhythm indicators) alone. For arrangements you want to read both ways, keep both staves visible; they render stacked in the order alphaTab derives from the source file.

Two side facts worth knowing:

- `standardNotationLineCount` overrides the default five. Percussion staves use 1, 2, or 3 lines; the setting also lets you build custom staves for hand-percussion, single-line rhythm parts, or historical notations.
- `displayTranspositionPitch` on a `Staff` shifts the notes on the standard staff without changing playback pitch. Guitar scores use `-12` so the notation sits inside the staff instead of hovering above it.

## Show it in code

```js
import * as alphaTab from '@coderline/alphatab';

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, {
  core: { file: '/scores/song.gp' },
});

api.scoreLoaded.on((score) => {
  for (const track of score.tracks) {
    for (const staff of track.staves) {
      staff.showStandardNotation = true;
      staff.showTablature = false;
    }
  }
  api.render();
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific step of obtaining the render target — a `<div>` on Web, an `AlphaTab` control on .NET, or an `AlphaTabView` on Android. Every other line runs unchanged on all three runtimes.
