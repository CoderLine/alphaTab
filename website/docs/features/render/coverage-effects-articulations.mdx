Guitar and bass articulations carry as much of the performance as the pitches do. alphaTab reads each articulation from the source file and renders it with the notation convention its instrument expects.

## Bends and whammy {#bends}

String bends — the trademark expressive move of blues and rock lead guitar — render as curved arrows above the tab and standard notation, annotated with the target pitch or interval. Whammy-bar dips (the bar-pushed pitch waver on tremolo-arm guitars) draw as a bar-level effect band with the pitch envelope over time.

<AlphaTab file="/files/features/Bends.gp5" />

## Vibrato {#vibrato}

Vibrato — the finger-driven pitch waver that sustains a note — renders as a wavy line above the affected notes. alphaTab draws a thin line for note vibrato and a thick line for beat-wide "wide" vibrato, so a reader can distinguish a subtle sustain shake from the exaggerated one common on lead solos.

<AlphaTab file="/files/features/Vibrato.gp5" />

## Palm mute and let ring {#palm-mute}

Palm mute (`P.M.`) — the muted-percussive strum common in metal riffs, punk, and funk — and let ring (`L.R.`) — the sustain instruction that keeps preceding notes ringing under new ones — render as bracketed labels above the affected beats, showing exactly where each technique starts and stops.

<AlphaTab file="/files/features/PalmMute.gp5" />

<AlphaTab file="/files/features/LetRing.gp5" />

## Taps, slaps, and pops {#tap}

Bass slap technique drives funk and slap-metal grooves: thumb slaps (`S`), string pops (`P`), and left-hand taps (`T`) render as letter markers above the notes. Two-handed tapping — the shred technique popularised by Van Halen — shares the same `T` notation.

<AlphaTab file="/files/features/Tap.gp5" />

## Dead slap {#dead-slap}

A dead slap is a percussive strike across all strings with the fretting hand muted, often used on flamenco and funk rhythm guitar. alphaTab draws it as a stack of dead-note heads (`x`) on every string.

:4 (3.6 2.5 0.4 0.3 0.2 3.1) ().4 {ds} :8 (3.6 2.5 0.4 0.3 0.2 3.1) (3.6 2.5 0.4 0.3 0.2 3.1) :4 ().4 {ds} |

`}</AlphaTab>

## Tremolo picking {#tremolo-picking}

Tremolo picking — rapid repetition of a single note, common on surf-rock leads and Iberian classical guitar — renders as slashes through the stem, matching the engraving convention of the standard notation staff.

<AlphaTab file="/files/features/TremoloPicking.gp5" />

## Slides, hammer-ons, and pull-offs {#slides}

Slides move the fretting finger to a new position while the note rings; hammer-ons and pull-offs sound a new pitch from the fretting hand alone. alphaTab draws slide-in, slide-out, legato, and shift slides as slanted lines between fret positions, and hammer-ons and pull-offs as curved slurs joining the linked notes.

<AlphaTab file="/files/features/Slides.gp5" />

## Trills {#trills}

Trills — the fast alternation between the written note and the pitch above it, a staple ornament from Baroque violin to modern lead guitar — render with a `tr` glyph above the notation staff and a wavy line indicating the duration.

<AlphaTab file="/files/features/Trill.gp5" />

## Pick strokes {#pick-stroke}

Downstroke (`⊓`) and upstroke (`V`) pick-direction markers tell a reader which way to strum each beat, useful for teaching charts where alternate picking or a strict downstroke pattern is the point.

<AlphaTab file="/files/features/PickStroke.gp5" />

## Fade-in and volume swells {#fade}

Fade-in and volume-swell markers — the volume-pedal or pinkie-wheel swell used on ambient guitar leads — render as text annotations paired with hairpins over the affected beats.

<AlphaTab file="/files/features/FadeIn.gp5" />

## Show it in code

Every articulation above is on by default. To hide one category — for example, palm-mute brackets in a printout — flip its `notation.elements` entry:

```js
import * as alphaTab from '@coderline/alphatab';

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, {
  core: { file: '/scores/song.gp' },
  notation: {
    elements: new Map([
      [alphaTab.NotationElement.EffectPalmMute, false],
      [alphaTab.NotationElement.EffectLetRing, false],
    ]),
  },
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific render target. See the [`NotationElement`](/docs/reference/types/notationelement) enumeration for every togglable category.
