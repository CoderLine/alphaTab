Guitar and bass articulations carry as much of the performance as the pitches do. alphaTab reads each articulation from the source file and renders it with the notation convention its instrument expects.

## Bends and whammy {#bends}

String bends render as curved arrows above the tab and standard notation, annotated with the target pitch or interval. Whammy-bar dips draw as a bar-level effect band with the pitch envelope over time.

<AlphaTab file="/files/features/Bends.gp5" />

## Vibrato {#vibrato}

Beat-level and note-level vibrato both render as a wavy line — thin for a note vibrato, thick for a beat-wide "wide" vibrato.

<AlphaTab file="/files/features/Vibrato.gp5" />

## Palm mute and let ring {#palm-mute}

Palm mute (`P.M.`) and let ring (`L.R.`) render as bracketed labels above the affected beats, showing exactly where the technique starts and stops.

<AlphaTab file="/files/features/PalmMute.gp5" />

<AlphaTab file="/files/features/LetRing.gp5" />

## Taps, slaps, and pops {#tap}

Bass slap technique — thumb slaps (`S`), pops (`P`), and left-hand taps (`T`) — renders as letter markers above the notes. Two-handed tapping shares the same `T` notation.

<AlphaTab file="/files/features/Tap.gp5" />

## Dead slap {#dead-slap}

A dead slap is a percussive strike across all strings with the fretting hand muted. alphaTab draws it as a stack of dead-note heads (`x`) on every string.

<AlphaTab tex="true">{`
().4 {ds} ().4 {ds}
`}</AlphaTab>

## Tremolo picking {#tremolo-picking}

Tremolo picking — rapid repetition of a single note — renders as slashes through the stem, matching engraving conventions of the standard notation staff.

<AlphaTab file="/files/features/TremoloPicking.gp5" />

## Slides, hammer-ons, and pull-offs {#slides}

Slide-in, slide-out, legato, and shift slides all render as slanted lines between fret positions. Hammer-ons and pull-offs render as curved slurs joining the linked notes.

<AlphaTab file="/files/features/Slides.gp5" />

## Trills {#trills}

Trills render with a `tr` glyph above the notation staff and a wavy line indicating the duration.

<AlphaTab file="/files/features/Trill.gp5" />

## Pick strokes {#pick-stroke}

Downstroke (`⊓`) and upstroke (`V`) pick-direction markers render above the beat on the tab staff.

<AlphaTab file="/files/features/PickStroke.gp5" />

## Fade-in and volume swells {#fade}

Fade-in and volume-swell markers render as text annotations paired with hairpins over the affected beats.

## Show it in code

Every articulation above is on by default. To hide one category — for example, palm-mute brackets in a printout — flip its `notation.elements` entry:

```js
import * as alphaTab from '@coderline/alphatab';

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, {
  core: { file: '/scores/canon.gp' },
  notation: {
    elements: new Map([
      [alphaTab.NotationElement.EffectPalmMute, false],
      [alphaTab.NotationElement.EffectLetRing, false],
    ]),
  },
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific render target. See the [`NotationElement`](/docs/reference/types/notationelement) enumeration for every togglable category.
