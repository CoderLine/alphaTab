alphaTab renders any number of tracks as a single vertical system, connects grand-staff instruments with a brace, and prints per-track tunings for stringed instruments. Reach for it whenever the reader needs to see how parts line up — a band-in-a-box view for a rehearsal app, a piano-and-voice pedagogical layout, or a full-score view of a jazz combo where soloists want the rhythm section on the same page.

## The grand staff for piano

A piano `Track` carries two `Staff` entries — a treble staff and a bass staff, tied together with a curly brace. alphaTab detects this from the source file and renders them stacked; the brace comes from the default `bracketExtendMode` of `GroupStaves`. Keep `showStandardNotation` on for both staves and `showTablature` off (piano staves ship with no tuning, so the tab staff is hidden automatically).

## Multiple tracks in one system

Selecting more than one track renders them as a single vertical system: the top track sits on the first line, brackets group multi-staff tracks, and every track shares the same barlines. Two paths get you there:

- **On the API constructor** — set `core.tracks` to an array of track indexes when you build the `AlphaTabApi`. The initial render includes exactly those tracks.
- **At runtime** — call `api.renderTracks(tracks)` with an array of `Track` objects. Use it to switch which players are visible without reloading the file: focus on a single soloist, expand to the whole ensemble, or hide backing parts on demand.

Each track keeps its own tuning label, transposition, and staff configuration. A score that mixes a 6-string guitar in standard tuning with a 5-string bass in drop-D prints both tunings above their respective staves at the start of the first system.

## Show it in code

```js
import * as alphaTab from '@coderline/alphatab';

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, {
  core: {
    file: '/scores/song.gp',
    tracks: [0, 1],
  },
});

api.scoreLoaded.on((score) => {
  // Switch to the piano alone at runtime.
  api.renderTracks([score.tracks[2]]);
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific step of obtaining the render target — a `<div>` on Web, an `AlphaTab` control on .NET, or an `AlphaTabView` on Android. Every other line runs unchanged on all three runtimes.
