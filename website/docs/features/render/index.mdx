The render engine walks the score model, applies traditional music-engraving rules, and draws the result through a pluggable canvas backend. alphaTab uses the [Bravura](https://github.com/steinbergmedia/bravura) SMuFL font for every glyph and re-flows the score when the container it lives in changes size.

Every capability below is available on Web, .NET, and Android unless a card names specific platforms. Follow any card into the [reference](/docs/reference/api/) for the exact signature.

## Adding a feature card {#adding-a-card}

Each card on this page comes from an `.mdx` file in this directory. Two kinds are supported:

- **Highlight page** — a full page with prose (e.g. [Per-element colors](/docs/features/render/per-element-colors)). Add `sidebar_custom_props.feature_chapter: <chapter-id>` to its frontmatter and it appears as a card. The card links to the page.
- **External-link stub** — a `.mdx` file that only exists to source a card. Set `unlisted: true` and `sidebar_custom_props.feature_external_link: <url>`. The card links to that URL and the stub is hidden from the sidebar.

Chapters are defined in [`_chapters.ts`](https://github.com/CoderLine/alphaTabWebsite/blob/main/docs/features/render/_chapters.ts) — add a new entry there to introduce a new H2 section. Full frontmatter schema lives in the [`FeatureChapterGrid` component source](https://github.com/CoderLine/alphaTabWebsite/blob/main/src/components/FeatureChapterGrid/index.tsx).
