Dynamics tell the reader how loud each passage is and how the volume changes over time. alphaTab renders the standard set — from `ppp` to `fff`, plus hairpins and per-note accents — below the notation staff.

## Static dynamics {#static}

Dynamic markings — `ppp`, `pp`, `p`, `mp`, `mf`, `f`, `ff`, `fff` — render in the dynamics italic font below the staff at the beat where they change.

<AlphaTab file="/files/features/Dynamics.gp5" />

## Crescendo and decrescendo hairpins {#hairpins}

Crescendo (`<`) and decrescendo (`>`) hairpins render below the staff, spanning every beat between their start and end.

<AlphaTab tex="true">{`
:4 C4 { dy pp } C4 C4 C4 { cre } |
C4 C4 C4 C4 { dy ff } |
C4 { dy ff } C4 C4 C4 { dec } |
C4 C4 C4 C4 { dy pp }
`}</AlphaTab>

## Accents {#accents}

Single-note accents render as marks above or below the notehead. alphaTab supports three levels — normal accent (`>`), heavy accent (`^`), and tenuto (`—`).

<AlphaTab tex="true">{`
:4 3.3{ac} 5.3{hac} 7.3{ten} 8.3{ac}
`}</AlphaTab>

## Show it in code

Dynamics are score-wide visible by default. To hide them — a common request for print layouts — set the stylesheet policy on the score model in a `scoreLoaded` handler:

```js
import * as alphaTab from '@coderline/alphatab';

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, {
  core: { file: '/scores/canon.gp' },
});

api.scoreLoaded.on((score) => {
  score.stylesheet.hideDynamics = true;
  api.render();
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific render target — a `<div>` on Web, an `AlphaTab` control on .NET, or an `AlphaTabView` on Android.
