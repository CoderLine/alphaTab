Chord information lives at two levels in a score — the diagram that shows the fingering and the inline chord name over a beat. alphaTab renders both, and the source file decides which appear where.

## Chord names on beats {#names}

Any beat can carry a chord name. alphaTab renders the name in the chord font directly above the beat, respecting sharp, flat, and slash-bass characters.

<AlphaTab file="/files/features/Chords.gp5" />

## Chord diagrams above the first system {#diagrams}

When a chord definition ships with a fretboard diagram, alphaTab draws it above the first system by default. The same score renders the diagrams inline above each referencing bar if you disable the top-of-score layout.

## Show it in code

Toggle whether diagrams collect above the first system or attach to each beat individually:

```js
import * as alphaTab from '@coderline/alphatab';

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, {
  core: { file: '/scores/canon.gp' },
  display: {
    chordDiagramsOnTop: true, // false to render each diagram above its beat
  },
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific render target — a `<div>` on Web, an `AlphaTab` control on .NET, or an `AlphaTabView` on Android.

To hide chord names or diagrams entirely, disable them through `notation.elements`:

```js
api.settings.notation.elements.set(
  alphaTab.NotationElement.EffectChordNames,
  false,
);
api.settings.notation.elements.set(
  alphaTab.NotationElement.EffectChordDiagrams,
  false,
);
api.updateSettings();
api.render();
```
