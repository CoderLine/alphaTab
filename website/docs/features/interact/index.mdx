Anything a reader does with the score — following the beat during a lesson, dragging out a phrase to loop it, tapping a note to audition it, snapping the viewport back to the cursor — flows through the APIs in this chapter. Cursors track the current beat, auto-scroll keeps that beat on screen, mouse and touch events fire for every beat and note the user hits, and the bounds lookup returns the same pixel geometry the renderer produced so overlays and hit-tests line up exactly.

Every capability below is available on Web, .NET, and Android unless a card names specific platforms. Follow any card into the [reference](/docs/reference/api/) for the exact signature.
