alphaTab keeps the rendered score in lockstep with playback and with the reader's pointer. Cursors track the current beat, auto-scroll keeps that beat on screen, mouse and touch events surface every beat and note the user clicks, and the bounds lookup lets you draw overlays or run hit-tests against the same geometry the renderer produced.

Every capability below is available on Web, .NET, and Android unless a card names specific platforms. Follow any card into the [reference](/docs/reference/api/) for the exact signature.
