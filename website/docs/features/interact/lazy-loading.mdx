alphaTab renders the score in small chunks. With lazy loading on, the chunks only enter the DOM when they scroll close to the viewport. Large scores paint fast, and the browser holds less markup at any moment.

<AlphaTab file="/files/canon.gp" player={true} />

## What lazy loading does

alphaTab breaks rendering into sub-chunks so the UI stays responsive during a long render. `core.enableLazyLoading` controls whether the finished chunks are appended immediately or held back until they are about to become visible.

- **`true` (default)** — chunks are appended when an `IntersectionObserver` detects they are near the viewport. Off-screen bars stay out of the DOM until the reader scrolls toward them.
- **`false`** — every rendered chunk is appended to the DOM the moment rendering completes.

Turn it off when the surrounding layout confuses the observer — a hidden tab that keeps the container off-screen forever, a transform-scaled ancestor, a portal into another document — or when you need every bar in the DOM for printing, screenshotting, or measuring.

The feature is Web-only. Other platforms append all rendered content immediately.

## Show it in code

```js
import * as alphaTab from '@coderline/alphatab';

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, {
  core: {
    file: '/scores/canon.gp',
    enableLazyLoading: true,
  },
});
```

`getAlphaTabContainer()` is a placeholder for the platform-specific step of
obtaining the render target. Every other line runs unchanged on all three
runtimes.
