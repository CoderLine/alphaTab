alphaTab renders every notehead, clef, accidental, dynamic, and ornament through a single SMuFL-compliant font. Bravura is the default; any other SMuFL font can take its place.

<AlphaTab file="/files/canon.gp" />

The [Using a custom music font](/docs/features/render/custom-smufl-fonts) page in the Render chapter walks the web-side wiring in three lines. This page covers the deeper story: which glyphs alphaTab draws from the font, what the metadata sidecar contributes, and what to check before adopting a new SMuFL font.

## What alphaTab draws from the font

alphaTab reaches into the SMuFL Standard glyph range for every graphical element that is not a text label. That includes:

- **Notation basics** — noteheads (round, X, slash, diamond, triangle), stems, flags, rests, augmentation dots, ties, and beams.
- **Signatures** — clefs (G, F, C, percussion, tab), key signature accidentals, and time signature digits.
- **Effects** — ornaments (trill, mordent, turn), articulations (accent, staccato, tenuto), fermatas, harmonics, palm mute, let ring.
- **Dynamics and directions** — dynamic letters (`ppp` through `fff`), crescendo hairpins, D.C. / D.S. / segno / coda symbols.
- **Guitar-specific glyphs** — bend arrows, whammy hooks, slide indicators, string tuning numerals.

A font that omits any of these ranges renders those elements as the font's placeholder or as blanks. Bravura, [Petaluma](https://github.com/steinbergmedia/petaluma), and [Leland](https://github.com/MuseScoreFonts/Leland) cover the full range alphaTab uses. Other SMuFL fonts vary — inspect the font's glyph inventory before committing.

## The two halves of a SMuFL font

Every SMuFL font ships as two files that must stay in sync:

- **The font file** — an `.otf`, `.woff`, or `.woff2` binary. alphaTab loads it via `core.smuflFontSources`, a `Map<FontFileFormat, string>` of URLs. Multiple formats can be listed at once; the browser picks the first it supports.
- **The `metadata.json` sidecar** — a JSON file published alongside the font describing engraving metrics: stem thicknesses, staff-line spacing, anchor points on each notehead. Fetch it and hand it to `display.resources.engravingSettings.fillFromSmufl()` so alphaTab spaces glyphs correctly.

Skip the metadata and the font renders with Bravura's spacing rules applied to different-shaped glyphs — the result looks subtly wrong at every scale. Skip the font file and the metadata has nothing to describe.

## Show it in code

```js
import * as alphaTab from '@coderline/alphatab';

const settings = new alphaTab.Settings();
settings.core.smuflFontSources = new Map([
  [alphaTab.FontFileFormat.Woff2, '/fonts/Petaluma.woff2'],
  [alphaTab.FontFileFormat.OpenType, '/fonts/Petaluma.otf'],
]);

const metadata = await fetch('/fonts/petaluma_metadata.json').then((r) => r.json());
settings.display.resources.engravingSettings.fillFromSmufl(metadata);

const container = getAlphaTabContainer();
const api = new alphaTab.AlphaTabApi(container, settings);
```

`getAlphaTabContainer()` is a placeholder for the platform-specific step of obtaining the render target — a `<div>` on Web, an `AlphaTab` control on .NET, or an `AlphaTabView` on Android.

## Building or picking a compatible font

If you want to author a new SMuFL font instead of adopting an existing one:

- Start from the [SMuFL specification](https://www.smufl.org/) — glyph codepoints are stable across every compliant font.
- Publish a `metadata.json` following the [Bravura reference](https://github.com/steinbergmedia/bravura/blob/master/redist/bravura_metadata.json). alphaTab reads `engravingDefaults`, glyph anchor points (`stemUpSE`, `stemDownNW`, `cutOutNW`, etc.), and bounding boxes.
- Ship at least `.woff2` and `.otf`. On .NET and Android alphaTab uses the OpenType variant.
- Cover the full glyph range alphaTab draws (listed above). Missing glyphs do not fall back — they render as gaps.

## Licensing

The default Bravura font is licensed under [SIL Open Font License 1.1](https://scripts.sil.org/OFL) and ships with alphaTab. Every SMuFL font you swap in carries its own license. Petaluma is SIL OFL 1.1; Leland is SIL OFL 1.1. Check the license of any font before redistributing it inside a commercial product — some SMuFL-compliant fonts are proprietary and require paid distribution rights.
