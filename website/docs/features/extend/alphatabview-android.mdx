Embedding alphaTab in a native Android app goes through `AlphaTabView` — a Kotlin `View` you position via XML or code that hosts the same rendering and playback engine as the web build. Every score format alphaTab supports, every setting, and every event on `AlphaTabApi` is available exactly as it is elsewhere.

Rendered here on the Web backend. On Android, `AlphaTabView` produces the identical output through the same `AlphaTabApi` surface — see the Kotlin below.

## Add the view to a layout

Declare the control inside any Android layout XML. Give it an id so the activity can obtain a reference:

```xml
<?xml version="1.0" encoding="utf-8"?>
<androidx.constraintlayout.widget.ConstraintLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto"
    android:layout_width="match_parent"
    android:layout_height="match_parent">

    <alphaTab.AlphaTabView
        android:id="@+id/alphatab_view"
        android:layout_width="match_parent"
        android:layout_height="match_parent" />

</androidx.constraintlayout.widget.ConstraintLayout>
```

## Drive it from Kotlin

Resolve the view, reach for its `api` property, and use the same `AlphaTabApi` surface the other platforms expose. Loading, rendering, event subscription, and playback all run through it:

```kotlin
import alphaTab.AlphaTabView
import android.os.Bundle
import androidx.activity.ComponentActivity

class MainActivity : ComponentActivity() {
    private lateinit var alphaTabView: AlphaTabView

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        alphaTabView = findViewById(R.id.alphatab_view)
        val api = alphaTabView.api

        api.load("file:///android_asset/scores/song.gp")

        api.scoreLoaded.on { score ->
            // apply styles, subscribe to playback events, adjust settings
        }
    }
}
```

## Jetpack Compose

There is no first-party Compose control today. Wrap `AlphaTabView` in an `AndroidView` composable to embed it inside a Compose tree:

```kotlin
import androidx.compose.runtime.Composable
import androidx.compose.ui.viewinterop.AndroidView

@Composable
fun AlphaTabScore(onReady: (alphaTab.AlphaTabView) -> Unit) {
    AndroidView(
        factory = { context -> alphaTab.AlphaTabView(context).also(onReady) },
    )
}
```
