alphaTab is designed to be embedded. When the shipped defaults are not enough, you can build scores in code, walk and mutate the loaded model, wire the worker and worklet into your own bundler, or host the engine in a native UI framework it does not already know about.

Every capability below is available on Web, .NET, and Android unless a card names specific platforms. Follow any card into the [reference](/docs/reference/api/) for the exact signature.
