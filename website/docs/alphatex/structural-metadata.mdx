This page documents the [structural metadata](./syntax#structural-metadata) scope — the [metadata tags](./syntax#metadata-tag) that open a new track, staff, or voice.

Use these tags when your song needs more than one of any of them:

* Multiple tracks — when several instruments play together in the same song.
* Multiple staves — for grand staff piano notation (left hand / right hand) or for splitting voices apart for readability.
* Multiple voices — for independent rhythms and pitches inside the same staff, such as vocal parts sung together or a bass line played under a melody on the same instrument.

Start each new track, staff, or voice with the matching tag at the beginning of a bar:

* `\track`
* `\staff`
* `\voice`

The first track, staff, and voice are opened implicitly, so you only need these tags from the second element onward. When a piece has more than one, name the first element explicitly for clarity.
