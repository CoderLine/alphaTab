alphaTex is a plain-text notation format for alphaTab. You write a score as source code and alphaTab parses it into the same data model any other format produces.

Enable alphaTex loading by setting the [`tex`](/docs/reference/settings/core/tex) option, or feed a string directly through the [`tex()`](/docs/reference/api/tex) method on the API. alphaTab reads the source from the element contents and parses it. You can also load it from a file the same way you load any other format.

alphaTex covers most of the notation features alphaTab supports. If a feature you need is missing, [open a discussion on GitHub](https://github.com/CoderLine/alphaTab/discussions/new).

Start with the [language syntax](./syntax) — it defines every term the rest of this section uses.
