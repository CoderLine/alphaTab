## `\title`

**Scope:** [Score metadata](./syntax#score-metadata)

```plain title="Syntax"
\title (value template textAlign)
```

**Description:** Set the title of the song.

**Parameters:**

| Name | Description | Type | Required |
|------|-------------|------|----------|
|  `value` | The value to set | `String` | yes  |
|  `template` | The template used to render the text | `String` | no  |
|  `textAlign` | The alignment of the text on the music sheet | `left\|center\|right` | no  |

**Parameter Values:**

Following parameters have value limitations

| Name | Values |
|------|--------|
| `textAlign` | <ParameterValuesTable values={[["left","Left-align the text"],["center","Center-align the text"],["right","Right-align the text"]]} /> |

**Example:**

<AlphaTexSample tracks="all" player={true} >{`
\\title ("Song Title" "Title: %TITLE%" left)
C4

`}</AlphaTexSample>

## `\systemsLayout`

**Scope:** [Score metadata](./syntax#score-metadata)

```plain title="Syntax"
\systemsLayout (numberOfBars)
```

**Description:** Defines the number of bars to display per system when rendering multiple tracks.

The `systemsLayout` and `defaultSystemsLayout` allow configuring the system layout. The system layout, defines how many bars should be displayed per system (line) if enabled via [`systemsLayoutMode`](/docs/reference/settings/display/systemslayoutmode).


**Parameters:**

| Name | Description | Type | Required |
|------|-------------|------|----------|
|  `numberOfBars` | Defines for every system (line) the number of bars it should contain | `Number[]` | no  |

**Example:**

<AlphaTexSample tracks="all" player={true} settings={{"display":{"systemsLayoutMode":"UseModelLayout"}}}>{`
\\systemsLayout (2 3 2)
\\track 
    :1 c4 | c4 | c4 | c4 | c4 | c4 | c4
\\track 
    :1 c4 | c4 | c4 | c4 | c4 | c4 | c4

`}</AlphaTexSample>

## `\defaultStaffDisplay`

```plain title="Syntax"
\defaultStaffDisplay (staffTypes)
```

**Description:** Defines the song-wide display of elements like clefs, key signatures, time signatures, rests and bar numbers.

The arguments select the staff types to which the properties apply. If no staff types are specified, every property applies to all staff types supporting the related element.

All properties are optional. Properties which are not specified keep their default. The values can be overridden per staff with [`\staffDisplay`](/docs/alphatex/staff-metadata#staffdisplay) and per bar with [`\barDisplay`](/docs/alphatex/bar-metadata#bardisplay).


**Parameters:**

| Name | Description | Type | Required |
|------|-------------|------|----------|
|  `staffTypes` | The staff types to which the properties apply. If omitted, every property applies to all staff types supporting it. | `score\|tabs\|slash\|numbered[]` | no  |

**Parameter Values:**

Following parameters have value limitations

| Name | Values |
|------|--------|
| `staffTypes` | <ParameterValuesTable values={[["score","Standard notation"],["tabs","Guitar tablature"],["slash","Slash notation"],["numbered","Numbered notation (Jianpu)"]]} /> |

**Example:**

<AlphaTexSample tracks="all" player={true} >{`
\\defaultStaffDisplay { clefPlacement primary }
\\defaultStaffDisplay tabs { tsVisibility true tsPlacement allStaves }
\\track
    \\staff {score tabs}
    3.3.4 3.3 3.3 3.3 | 3.3 3.3 3.3 3.3

`}</AlphaTexSample>
