An alphaTex file is a list of bars. Each bar carries optional [metadata tags](./syntax#metadata-tag) followed by its beat content. Place song-wide metadata at the top of the file and any external media sync points at the bottom.

```title=General File Structure
/* Song Metadata */
/* Song Contents */
/* Sync Points */
```

:::note
Before alphaTex 1.7 the three sections had to be separated by a `.`. Since 1.7 the separator dots are optional and you should omit them.

```title=Pre 1.7 File Structure
/* Song Metadata */
.
/* Song Contents */
.
/* Sync Points */
```
:::

## Bars

A bar (also called a measure) begins with an optional list of [bar metadata tags](./syntax#bar-metadata) and continues with the beats it contains. See [Bar Metadata](./bar-metadata) for the tags you can apply here.

Close a bar with a pipe `|`.

<AlphaTexSample>{`
// bar 1 metadata tags
\\clef G2 \\ks 
    // bar 1 contents
    Cb C4 
|  
// bar 2 metadata tags
\\ks A
    // bar 2 contents
    C4 
`}</AlphaTexSample>

## Beats

A beat groups notes that sound at the same time. The general shape of a beat is:

* `duration-change content duration effects multiplier`

<AlphaTexSample tracks={"all"}>{`
:4
    C4
    (C4 D4).8
    (C4 D4) { f }
    C4.16 * 2
    C4.4 
`}</AlphaTexSample>

### Duration change (optional)

Change the duration for every following beat with `:Duration`, where `Duration` is one of:

* `:-4` a Quadruple Whole Note
* `:-2` a Double Note 
* `:1` a Whole Note
* `:2` a Half Note
* `:4` a Quarter Note 
* `:8` an 8th Note 
* `:16` a 16th Note
* `:32` a 32nd Note
* `:64` a 64th Note
* `:128` a 128th Note 
* `:256` a 256th Note 

You can attach a [property block](./syntax#property) after the duration to declare tuplets.

`:4 {tu 3 2}`

See [Tuplet Effect](./beat-properties#tu) for details.

<AlphaTexSample>{`
:16 // 16th notes from here
    3.3
    4.3 
    5.3
    6.3
:4 { tu 3 } // quarter notes triplets
    3.3
    4.3
    5.3
:8 
    3.3 * 3
`}</AlphaTexSample>

### Beat Content (required)

The content of a beat is one of:

* A rest
* Multiple notes played together (grouped by parentheses)
* A single note

Write a rest as `r`.

<AlphaTexSample>{`
:4 r r r r
`}</AlphaTexSample>

Group multiple [Notes](#notes) with parentheses `()`. As with [argument lists](./syntax#argument-list), you can omit the parentheses when there is a single note.

<AlphaTexSample>{`
:4 
    C4 // single note on beat
    (C4 E4) // multiple notes with parenthesis
`}</AlphaTexSample>

### Beat Duration (optional)

You can also set the beat duration after the beat content as `. duration`. The new duration is remembered for the next beat, but tuplet effects are not.

<AlphaTexSample>{`
C4 .4
C4 .8
C4 // .8 remembered
C4 .2
`}</AlphaTexSample>

### Beat Effects (optional)

Attach [beat properties](./syntax#beat-property) after the beat content. See [Beat Properties](./beat-properties) for the full list.

<AlphaTexSample>{`
:4
    (C4 D4) { tp 8 } 
    C4 { f }
    r.2 {txt "Pause here"}
`}</AlphaTexSample>

### Beat Multiplier (optional)

Repeat the same beat with `* times`, where `times` is the number of copies.

<AlphaTexSample>{`
:4
    // 4 times the same A-chord 
    (0.1 2.2 2.3 2.4 0.5) * 4 
`}</AlphaTexSample>

## Notes

Depending on the instrument, a bar contains one of three note kinds. Do not mix them within a staff — pick one and stay with it:

* Fretted and stringed instruments (guitars and similar) use [`fret.string`](./syntax#fret-string).
* Percussion and drums use articulation names.
* Other pitched instruments use note names.

After each note you can attach [note properties](./syntax#note-property) as `note-value {note-properties}`.

:::info
alphaTab detects the staff kind from the first note it reads.
:::

### Fretted Notes

When the current staff is a stringed instrument (`\tuning` or `\instrument` set accordingly), you write notes as [fret and string](./syntax#fret-string). alphaTab computes the resulting pitch.

<AlphaTexSample>{`
:1
    (12.1 {sib} 14.2 {sib b (0 4)})
    12.1 { v }
`}</AlphaTexSample>

### Percussion / Drum Notes

On percussion instruments, write the articulation to play as the note value. Use a quoted string or an unquoted identifier.

See the [`\\articulation`](./staff-metadata#articulation) metadata tag for details.

<AlphaTexSample>{`
\\instrument percussion
\\articulation defaults
:4
    (KickHit RideBell) 
    r 
    KickHit 
    KickHit
`}</AlphaTexSample>

### Pitched notes

A pitched note combines:

* The tone (`C`, `D`, `E`, `F`, `G`, `A`, `B`, `C`)
* The accidental (`#`, `b`, `bb`, `x`, `##`, …; see [Accidentals](./note-properties#acc) for details)
* The octave (a number)

<AlphaTexSample>{`
C4
C#4
Ebb4
Dx5 
`}</AlphaTexSample>

### Note Effects

See [Note Properties](./note-properties) for the full list of note-level effects.

<AlphaTexSample>{`
:2
    3.3 { b (0 4) } // note bend
    (
        3.3 { v } // Vibrato
        3.2 { sib } // slide into from below
    )
`}</AlphaTexSample>

When a beat holds a single note, you can combine note and beat properties in one block.

<AlphaTexSample>{`
:2
    // combined effects
    3.3 {
        b (0 4)     // note effect
        txt "Bend"  // beat effect
    }
    // separated effects 
    3.3 
        { b (0 4) }     // note effect
        { txt "Bend" }  // beat effect
`}</AlphaTexSample>

## Tracks, Staves and Voices

A song can hold multiple tracks and staves. Dedicated [structural metadata tags](./syntax#structural-metadata) mark the start of each. See [Structural Metadata](./structural-metadata) for the full reference.

<AlphaTexSample tracks={"all"}>{`
\\track "Track 1"
    \\staff {score} // first staff
        \\voice // first voice 
            C4 D4 E4 F4 | C4 D4 E4 F4
        \\voice // second voice
            C5 D5 E5 F5 | C5 D5 E5 F5
    \\staff {tabs} // second staff
        3.5 5.5 7.5 8.5 | 3.5 5.5 7.5 8.5
\\track "Track 2"
     1.2 3.2 5.2 6.2
`}</AlphaTexSample>

You only need to write these structural tags to start a new element. The initial track, staff, and voice are opened implicitly.

<AlphaTexSample tracks={"all"}>{`
// first track
    // first staff
        // first voice 
            C4 D4 E4 F4 | C4 D4 E4 F4
        \\voice // second voice
            C5 D5 E5 F5 | C5 D5 E5 F5
    \\staff {tabs} // second staff
        3.5 5.5 7.5 8.5 | 3.5 5.5 7.5 8.5
\\track "Track 2"
     1.2 3.2 5.2 6.2
`}</AlphaTexSample>
